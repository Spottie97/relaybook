# Relaybook logo

The mark is two nodes and a baton moving from the left node into the right one. That is the planner handing work to the executor.

## Files

- `logo-mark.svg` is the symbol alone. It uses `currentColor`, and it stays legible at 16px and 32px.
- `logo-light.svg` is the lockup for white and other light backgrounds.
- `logo-dark.svg` is the lockup for GitHub dark (`#0d1117`) and other dark backgrounds.
- `social-preview.svg` is the source for `social-preview.png` (1280×640).

## Palette

The accent is one teal. A single hex cannot reach 4.5:1 on both white and `#0d1117`, so each lockup uses the stop that clears its background.

| Ink or accent | Background | Contrast |
| --- | --- | --- |
| `#1C2430` | `#ffffff` | 15.62:1 |
| `#0C5C58` | `#ffffff` | 7.81:1 |
| `#E8EEF5` | `#0d1117` | 16.20:1 |
| `#7EE0D6` | `#0d1117` | 12.18:1 |
| `#B7C3CE` (tagline) | `#0d1117` | 10.55:1 |

## Wordmark

The wordmark is Inter SemiBold, and the social tagline is Inter Regular, both converted to outlines. Inter is under the SIL Open Font License 1.1 (<https://github.com/rsms/inter>). The font files are not in this repo.

## Social preview

GitHub has no API for the social preview image. Upload `assets/social-preview.png` under Settings, General, Social preview.
